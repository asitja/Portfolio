# Portfolio — Aurélie Sitja

Bienvenue ! Ce site est mon **portfolio personnel** : il me présente, ainsi que mon parcours, mes compétences et mes réalisations en tant qu'**ingénieure du numérique**.   
Voilà le lien pour y accéder : https://asitja.github.io/Portfolio/   

## Ce que l'on y trouve

- **À propos** : qui je suis et ce que je recherche
- **Formation** et **compétences**
- **Expériences & réalisations** : stages et projets universitaires, avec images et rapports PDF consultables directement dans le site
- **Recommandation** : lettre de recommandation
- **Projets personnels** : démonstrations interactives
  - [Blokus](projets/blokus) — jeu de plateau
  - [Tour de cartes](projets/tourCartes) — tour mathématique basé sur les mélanges riffle
- **CV** téléchargeable et lien LinkedIn

## Technologies

Site statique en **HTML, CSS et JavaScript**, sans framework ni dépendance externe.

## Structure

```text
index.html, style.css, script.js   Page principale du portfolio
documents/
  autres/                          CV, lettre de recommandation, logo
  images/                          Photos et visuels des réalisations
  rapports/                        Rapports de stage et de projets (PDF)
projets/
  blokus/                          Démonstration Blokus
  tourCartes/                      Démonstration du tour de cartes
```

## Lancer le site en local

Ouvrir simplement `index.html` dans un navigateur, sans serveur nécessaire.

## Contact

Retrouvez-moi sur LinkedIn (lien dans le site) ou via mon CV dans `documents/autres/`.
